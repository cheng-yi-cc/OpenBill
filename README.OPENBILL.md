# OpenBill 使用与开发入口

项目概览和安装入口见 [README](README.md)，覆盖升级、完整备份及恢复见 [运维说明](docs/OPENBILL_OPERATIONS.md)。仅发布 Android 应用。

## 从空账本开始

1. 在“资产 → ＋”建立银行卡、现金或支付账户。仅从启用日开始记账时填当前余额；导入历史流水时填对应的历史起始余额，避免重复累计。
2. 在“我的 → 账本管理”创建账本，可设置首页与日历是否显示转账和投资结算流水，也可先隐藏当时已有的收支分类；以后新增的共享分类仍按自身范围显示。分类管理右上角可按账本调整父分类和子分类的显示。这些设置不会改变历史账单、账户余额或收支统计。流水、模板和分类可按账本管理，资金账户在各账本间共用；移动流水不会再扣款，归档账本只供查询。账本菜单中的“账单迁移”可将来源账本的全部普通流水、关联退款、报销到账、转账及同账本有效投资事件在同一事务迁至目标账本（跨账本关联分裂记录仍会受保护拒绝）。隐藏账本后可在管理页的“已隐藏账本”中恢复；当前账本被隐藏时仍可继续记账。
3. 使用中间记账按钮录入支出、收入、转账或债务。分类、标签、备注、日期、附件和四则金额键盘在同一流程中使用；“再记”保存后继续下一笔。
4. 在“资产 → ＋”建立证券、加密交易所或钱包。录入已有持仓不扣资金账户；新买入才记录实际支付。成本不清楚可留空，未知成本不会按零计算盈利。

## 首页、记账与我的

手机默认使用干净浅色主题。首页可搜索账单、用 `#标签 空格` 精确匹配标签，组合日期、金额、备注、地点、账本、账户、报销、分类、标签及附加条件；支持历史记录、金额排序、多选移动/删除、CSV 或 Excel 导出、图片账单。右上角菜单提供数据小卡片、模板、预算、简洁/详细显示、全部/月度范围以及微信/支付宝截图导入。

记账页集中显示分类、标签、备注、同行四则运算键盘，以及日期、账户、报销、附件、优惠、属性。从账户详情带入或手动选择的账户不会因切换分类而被默认账户覆盖；没有明确选择时可按分类、上次账户或固定账户建议。人民币或美元普通资金账户记录收支时，可点击金额左侧币种符号（`¥`/`$`）无动画切换记账币种，按系统汇率自动折算入账，并在列表和详情中保留原币金额与记账汇率。优惠按原价/优惠/实付计算；转账手续费正数为支出、负数为优惠收入，和转账一起保存、修改、删除。同币种转账可在手续费页面输入含手续费的扣款总额，计算实际转账本金；跨币转账需分别核对实际金额。借入/借出可填写约定还款日期，在日历生成关联事项；提醒不自动记还款。地点可填文字，也可申请系统定位权限。

“我的”提供本机昵称/头像、周期记账、愿望清单、分类关键词、账本/标签/分类管理、更多设置（含「关于 OpenBill」检查 GitHub Releases 更新与原位覆盖升级）、完整备份、导入导出、账单图片与主题。愿望的手动储蓄或计划进度不修改账户余额；分类关键词只为导入预览匹配已有分类、账户和标签。

“我的”将周期记账、愿望、关键词、账本、标签、分类和更多设置集中在常用入口。标签管理按一级标签卡片和子标签展示，可新增、编辑、隐藏、排序、分组和查看关联账单；分类管理直接切换支出、收入、转账，展开一级分类管理二级分类，并保留图标、颜色和生效账本设置。排序先预览，保存后生效，取消不改变原顺序。

数据卡片可选择内容、统计周期、账本/账户/分类/标签范围、大小、颜色、背景照片和透明度并排序。预算复用实际账务口径；待报销显示尚未到账金额。黄金卡片展示已绑定的黄金标的报价；历史资产走势需要已有有效快照。缺少换算或报价保持未知。

导入支持原有文件解析器、CSV/Excel 字段映射和本机离线截图识别。识别结果须核对账户、分类、金额和时间后确认，疑似重复默认不选；缺失日期暂填识别当天，缺失时间暂填 12:00。每次导入作为一批保存，可在导入记录中整体撤回。CSV/Excel 是账单交换文件；完整还原优惠、手续费关联、附件和其他业务须使用完整备份。

当前版本不提供登录入口、云同步、第三方账单自动采集、扫一扫、AI 截图记账、文字智能记账或语音识别；保留普通文件和离线截图导入。自动记账暂不开发。显式设置的周期计划、基金收益与加密定投按各自规则处理。

## 资产入口

| 入口 | 操作与口径 |
|---|---|
| 资产首页 | 净资产、资产/负债、报销/债务/理财摘要、分组折叠、金额隐藏、账户排序与隐藏 |
| 新建/编辑账户 | 资金、信贷、预付卡、保险、房产/车辆、自定义、债务、报销及投资账户；简称、备注、卡号、图标、分组、生效账本和计入总资产 |
| 资金账户详情 | 记账、转账、余额校准、余额变动、资产明细、转账记录、流水对账、CSV 导出、定期存款及编辑/删除 |
| 收益同步 | 从人民币资金账户编辑页进入；只填基金名称、代码、开始计息时间，名称/代码均可搜索；解绑保留历史收益 |
| 报销 | 创建报销账户，记支出时选择报销对象；在待报账单记录一次或多次到账，可结束/恢复或取消报销 |
| 债务 | 追加借入/借出、分次还款/收回、利息/优惠、还款日期、方向转换和结清隐藏；本金不重复计入收支 |
| 信用卡 | 额度/共享额度、账单日、还款规则、年费条件、各期账单、还款记录及分期管理 |
| 定期存款 | 记录已在账户内的本金、利率、期限、开始日期，查看预计收益、到期结算或提前结束 |
| 投资与加密账户 | 股票、基金、加密资产和其他持仓；买入、卖出、币币兑换、账户转移、历史修订及撤销 |

长按账户或使用详情菜单可删除。先查看关联记录预览，再选择处理关联交易或确认级联删除。转账双边、投资事实和其他账户余额会一起校验、更新；剩余投资历史不成立时整次取消。系统结算账户不能删除。

余额校准保留差额流水，可选是否计入收支；生成收支账单时可选择账本、分类、备注和标签。房产、车辆、保险、预付卡沿用账户余额，不提供市场自动估价。信用卡分期不重复增加本金负债；费用按计划独立入账，实际还款须另行记录。账单和日历区分已入账待还与包含未来分期费用的预计待还；预存转入信用卡后先抵较早的计划费用。单笔消费退款后可分期的本金扣除退回原卡的金额，退款到其他账户不减少本卡欠款；支持含退款的月账单还款分期，以及消费分期后的退款按“冲抵应还（`offset`）”或“缩减分期本金（`reduce`）”联动处理。

货币基金仅对显式绑定的账户生成收益，按账内交易和起息规则计算；这不等于银行或基金平台实际结算。定存本金不再次增加资产，并从其有效期内的货币基金计息本金扣除。新增、修改或终止定存以及回溯变更资金流水若会改变已处理日期的计息本金，当前会保守拒绝，不能自动重算既有收益；不影响这些日期本金的备注和利率修改仍可进行。删除关联账户或清除单账户账务时也会保护其他保留账户的已处理收益。普通证券/加密行情只改变参考估值。

### 加密货币每日定投

从“资产 → 加密货币交易所账户 → 每日定投”添加计划。支持用定量 USDT 或 USDC 每日买入 BTC、ETH、SOL，分别填写投入数量、时间、开始日期和账本，时区使用用户当前设置并保存到计划。

这是与交易所计划对应的本地参考记账：不连接交易所账户、不提交订单。应用运行时检查到期安排；关闭后重新打开，按指定分钟的历史公开价格补记，缺少历史价格或人民币汇率则保留待处理。稳定币和买入币均读取实际公开价格，不把稳定币固定为 1 美元；手续费默认为 0，实际成交有差异时可修订投资流水。

扣款从所选交易所已有的稳定币持仓中发生，并和买入、成本、防重记录一起原子保存。不足一次扣款时直接暂停，不生成买入；补足后须手动恢复，从下次计划时间继续，暂停期间不补买。多个计划共用同一稳定币时，按合计未来三天用量弹窗提醒，每个会话每天去重。

计划显示累计投入、累计买入及人民币买入成本；成本与收益详情显示该账户同币种合并后的剩余成本、平均成本和未实现盈亏。人工撤销不会让同一天再次自动买入。调整计划只影响后续安排，原有待处理安排停止，已入账事实保留。

### 手机理财

从“资产 → 理财”进入分组列表，顶部查看计入净资产金额和累计收益；搜索只筛选列表，不改变顶部汇总。隐藏项目仍计入汇总，“不计入总资产”才排除；列表与统计采用同一账本和账户范围。可搜索、新增基金、股票、港股、美股、期货/贵金属、自定义理财及加密账户。货币基金沿用绑定资金账户的余额和有效收益流水，不再建立一份本金。

新增理财按“所属账户 → 产品 → 持仓或成交”填写，可选择已有投资账户或同时建立新账户。“录入已有持仓”不扣资金，“记录一笔买入”将新产品、持仓和实际扣款一次提交；买入需要已经确认的成交份额。基金代码或名称可查询公开身份，也可开启“手动记录（未绑定行情）”，填写名称、代码及可选参考价，查询失败不阻止手动保存。货币基金仍沿用原账户绑定流程。

详情页显示持仓、每份成本、总成本、参考价格与交易记录。卖出默认填写实际到账金额，可一键使用全部份额，手续费单列；金额明确标注结算账户币种。“更多 → 编辑持仓”和“编辑账户”分别管理持仓事实与平台信息。修改份额或成本会留下可撤销的持仓校准记录；低频的“对账修正”仅调整累计收益展示，并标明显示修正，不改变真实盈亏曲线。

加密已有持仓可填写人民币总成本和实际发生时间；未知成本留空。账户间转移分别记录总扣除、实际到账和同币手续费。补记历史兑换不能用当前报价确立历史成本，缺少历史换算时保持未知。同一公开身份的加密币跨账户合并，列表显示市值、今日及累计收益，数量、成本和报价细节在详情查看。今日收益仍依据会计零点历史收盘价及历史汇率回放，不用 24 小时涨跌替代。

资产首页、理财列表、统计及相关详情共用本次会话的金额隐藏状态；编辑表单仍显示需要核对的事实。公共数据分项加载，某一接口失败时保留已取得的持仓并提示具体失败项；同一账户内部分持仓缺少报价或汇率时保留“已知”小计并明确标注缺失项，全部未知时显示 `—`。

账单详情采用居中日期/时间滚轮弹窗与逐项直编：普通账单可直接在详情页点击修改日期、账户、转入金额、手续费、优惠、备注、标签、附件、账本、地点、约定还款日、计入收支/预算及手动关联账单，并支持点击分类/标签/账户下钻统计或明细；信用卡支出可直接查看/新增关联分期，底部保留再记一笔、退款与编辑。投资买卖结算流水显示买卖方向和可用的产品名称；账户流水每日小计按实际资金流入、流出计算，包括转账和投资结算。转账和关联手续费完整加载后在转出账户合并展示，优惠抵减转出金额；分页未加载完整时暂时分别显示。自动货币基金收益可展开查看收益日期、万份收益和计息本金。应用前台每分钟检查尚未公布的收益，成功补记后自动刷新账单和理财页面；实际可入账时间取决于数据源发布与网络。

“理财定投”支持每天、每周、每两周和每月，设置起止日期、时间、付款账户、含费总额及费率。到期后使用公开历史净值入账，15:00及以后或非净值公布日顺延；确认份额保留两位小数，属于估算，可按实际成交修订。应用打开或保持前台时执行，关闭期间的到期记录在重开后分批补齐。净值缺失、余额不足和未来确认日期保留待确认，未确认前不扣资金或增加持仓；可手动填净值或取消本期。暂停、删除计划或撤销已入账事件都不会重复生成原期扣款。

理财统计可筛选交易日期、查看买卖投入和费用、实际已记录的历史收益曲线，并导出单项流水。年化为按资金占用日计算的简单估算，转移、校准或缺失成本/价格时不显示结果；历史曲线不会用今日价格补造。

### 账户单位与选择

添加加密交易所/钱包时可按品牌搜索 25 个常用平台并离线展示对应图标，也可留空使用自定义名称与通用图标；Bitget Wallet 与 Bitget 交易所为不同选项。首次添加支持填写持有数量、总成本与每枚均价双向换算（美元成本须填写当时人民币汇率，未知成本留空），交易所还可在同一页面直接配置多条每日定投并原子保存。

钱包/交易所的“编辑账户 → 货币单位”可随时选择人民币或美元，账户市值和新增收支默认跟随，总资产仍按人民币汇总，旧账单保留原币金额与当时汇率。在“收支默认币种”设置优先扣款/默认收款币种及备用支出币种，例如 USD24 优先、USDC 补足。账户详情的“记支出 / 记收入”可直接使用；首页普通收支的账户选择也包含钱包。默认按每枚约 1 美元估算数量，保存前可按实际交易修改；这不会把市场报价固定为 1 美元。人民币录入用参考美元汇率估算数量，缺失汇率或历史日期需填写实际数量。收支保存、修订和撤销同步更新持仓、分类账单与人民币统计，避免重复增加或扣减资产。

钱包收支已支持标签、地点名称、附件图片、优惠金额，并可分别设置不计入收支、不计入预算和隐藏金额；普通记账切换钱包时会带入这些内容。钱包收支目前尚不支持报销和地图坐标。普通记账草稿包含这些未支持字段，或已有金额而钱包使用不同货币单位时，选择钱包会提示并保留草稿；请先处理这些内容。钱包分类选择遵循当前账本的分类显示设置。

普通资金账户仅在零余额且无历史及计价规则时可修改货币单位，已有余额或流水的账户保持原币种。银行卡与信用卡按名称或常见简称自动显示银行标志，覆盖工行、农行、中行、建行、交行、邮储、招行等 19 家；自上传图标保留，无法唯一识别时使用原图标。

新增记账选择账户时，按资产页顺序直接平铺所有可选账户，保留图标、余额和搜索，点击即可选中，无需先选择账户分类。支出、收入与转账使用一致的列表；账户隐藏、账本范围及各记账类型的可用限制继续生效。

## 日历、统计与提醒

统计中的资产走势使用真实历史时间刻度、细线和渐变填充，可切换净资产/已估值资产、放大并触摸查看金额。横轴不延伸到未来日期；单条历史记录显示为独立点，缺失日期或未知估值保留断点，不补造历史余额。图表跟随深浅主题实时切换。

日历按用户时区、每周起始日显示收支、农历/节气、手动事项和到期安排；信用卡账单与定存到期信息来自对应记录，手动提醒会单独标明。定存到期项显示预计收益，可进入定存记录管理；账户详情按账户余额和未到期定存本金展示活期与定存，预计收益不会提前入账。日历账本筛选独立于首页，可选择重启后保留，并随完整备份恢复。事项自身不改余额。

统计提供“日常 / 月统计 / 年统计 / 自定义”四个入口，支持多账本和账户/分类/标签筛选、展开收支摘要、柱线切换与放大、历史资产走势、收支对比、分类/账户/标签占比、分类同期比较、可排序报表与账单下钻、年度热力图及月年总结。右上角菜单可分别调整四种周期的模块显示与顺序，复制或导出消费分析文本。

日常统计的“预算占比 → 查看详情”进入月预算、分类预算和自定义预算；可设置后续沿用、余款/超支结转、日均预算及进度条口径。普通支出可分别设置是否计入收支和预算，均不改变账户余额；旧账单继续沿用原有合并设置，直到明确修改。预算由实际支出重算，不维护另一份账户余额；内部转账、投资结算、报销和不计预算的账单排除，退款冲减原支出。外币缺少历史汇率时保持未知。

普通支出详情可新增、修改和删除关联退款；原账显示净支出，到账账户保留实际退款流水。超出原支出的部分作为无账户收入参与统计，不重复增加账户余额。报销支出也可退款，已报销到账不会被抹去，剩余可报金额随退款重算。已有报销到账的原账须先处理到账记录才能删除；在账单搜索结果多选原支出并移动账本时，有效退款和报销到账会同时迁移，余额不变；超额退款独立指定的账本保持原设置。为保护关联，不能在单笔编辑中单独改变已有到账的报销支出或到账流水的账本；关联退款的账户清账及级联删除仍受保护，须先单独处理关联记录。CSV/Excel 展示净额，完整恢复退款关系须使用完整备份。

标签支持两级，在标签管理或新建标签时选择上级；统计可选择所有标签、一级含子级、一级不含子级或二级，按一级含子级汇总时同一账单不会重复计数。普通收支记账可填写优惠金额；账单金额仍为实际支付/到账，优惠不会再次改余额。共享成员不在当前单人版范围内。

资产提醒可组合信用卡、借款日期、手动事项及定存到期。定存生成的到期事项须通过定存记录修改或终止；单账户清账前须处理尚未结算的定存。Android 通知需要系统授权；应用被停止期间不保证持续计算，重新打开时补齐可结算记录。

## 行情与未知值

搜索后核对市场、代码、来源和币种再绑定。同名资产不自动合并；手动价格优先。证券、基金、加密报价和人民币汇率保留各自日期与状态，缺失值不按零处理，报价过期会明确标记。国内与海外来源使用独立连接池，可配置自建行情中转；网络边界、部署及 Android 配置见 [行情网络说明](docs/OPENBILL_MARKET_NETWORK.md)。中转尚需自行部署和配置，不默认具备免 VPN 访问能力。

手机端搜索不到的币种，可从“搜索更多加密货币 → 找不到币种？手动添加”填写名称与代码，再录入持有数量。保存后进入币种详情的“手动估值”，加密货币默认填写每枚美元价格，也可切换人民币；股票、基金等仍填写人民币价格。美元原价会保留，人民币市值按最新已公布的美元汇率自动折算，并显示汇率来源与实际日期；原有人民币报价仍按人民币解释，缺报价或汇率时人民币估值保持未知。手动报价只改变估值，不改变数量、成本或资金流水，也不会自动将同名币种合并。比如 Arbitrum 合约 `0xbE00f3db78688d9704BCb4e0a827aea3a9Cc0D62` 对应 [Fiat24 USD（USD24）](https://docs.fiat24.com/developer/integration-guide/part-1-smart-contracts)，不应当成 USDT 添加或套用 USDT 行情。

人民币买币可选“按付款金额”或“按买入数量”，买入单价由用户填写：付款金额除以单价得到数量，数量乘以单价得到付款金额；人民币四舍五入到分，输入的买入数量保持不变。此流程无需参考行情，扣款和持仓仍原子保存。币币兑换与卖币的行情换算只供参考，实际支付/到账由用户确认；缺少历史换算依据的成本和盈亏保持未知。供应商、刷新规则、可选密钥及联网检查见 [行情模块](pkg/marketquotes/README.md)。

## Android 开发与本地预览

工具路径、签名和升级步骤见 [Android 说明](android/README.md)。在项目根执行：

```powershell
python scripts/build_android.py --qa
adb install -r dist/android/OpenBill-Android-arm64-qa.apk
adb shell am start -n com.cyledger.android.qa/com.cyledger.android.MainActivity
```

手机打开 **OpenBill 测试** 即可预览图标、冷启动动画和界面。QA 使用独立虚构账本；正式版使用同一签名构建并覆盖升级，不能卸载或清除数据。只预览前端布局可用 `npm run serve` 后打开 `http://localhost:8081/mobile.html`，它不是独立电脑产品，也不具备原生会话和系统功能。

按本次修改范围执行检查：`node node_modules/vue-tsc/bin/vue-tsc.js --noEmit`、`npm run build`、相关 Vitest、Go 核心与 SQLite 集成测试。验收范围见 [交接记录](docs/OPENBILL_ACCEPTANCE.md)。
